Privacy Policy

Pepper Dashboard · Effective date: 2026-10-03

Pepper Dashboard is a personal, single-user assistant dashboard built and used by Jose Villalba. It is not offered to the public and has no other users. This policy describes how it handles Google user data.

Data accessed

Calendar event data only, through the read-only scope https://www.googleapis.com/auth/calendar.events.readonly. The app cannot create, change, or delete events, and it requests no other Google scope.

How the data is used

To answer Jose's own questions about his schedule. When he asks about a date or range, the app fetches the matching events from his calendar and uses them to compose the answer. Nothing else is done with the data.

Third-party processors

Pepper Dashboard uses two external services to do its job:

  • Anthropic (Claude API). The event details returned for a question (such as title, date, and time) are sent to the Anthropic Claude API so it can generate the answer.
  • OpenAI (speech API). When a reply is spoken aloud, the reply text is sent to OpenAI's speech API to produce audio. That text may mention event details if the reply does. Calendar data is not otherwise sent to OpenAI.

Data is not shared with anyone else, is not sold, and is not used for advertising.

Storage

The Google OAuth token is stored locally, in a file on Jose's own machine. The app has no database and does not keep a copy of calendar events: they are fetched when asked and not saved by the app.

Retention and deletion

The access stays in place until it is removed. To end it, revoke Pepper Dashboard's access at https://myaccount.google.com/permissions and delete the local token file from the machine.

Limited Use

Pepper Dashboard's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions can be raised as an issue at https://github.com/Josevventures/pepper-privacy/issues.

Changes

Updates to this policy will be published on this page with a new effective date.
