# pepper-privacy

Static homepage, privacy policy, and terms of service for **Pepper Dashboard**, a personal, single-user assistant dashboard that reads the author's own Google Calendar (read-only). These pages exist to satisfy Google OAuth app verification requirements.

Served by GitHub Pages: https://josevventures.github.io/pepper-privacy/

- `index.html` - homepage
- `privacy.html` - privacy policy
- `terms.html` - terms of service

Plain HTML with inline CSS. No JavaScript, trackers, or external resources.
